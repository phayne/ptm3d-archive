OPTION 2: MERMAID DIAGRAM (for GitHub rendering or mermaid.live)
================================================================================

Copy the code below and paste into:
- GitHub README (in ```mermaid code block)
- https://mermaid.live for PNG/SVG export

```mermaid
flowchart TD
    subgraph INPUTS["📥 INPUTS"]
        mesh[("Mesh File<br/>(PLY/OBJ/VTK)")]
        spice[("SPICE Kernels<br/>(Ephemeris)")]
        config[("Config File<br/>(YAML)")]
    end

    subgraph PROCESSING["⚙️ PROCESSING"]
        meshgen["🔷 Mesh Generation<br/>• Icosphere creation<br/>• Normal computation<br/>• Area calculation"]

        illum["☀️ Illumination Model<br/>• Ray tracing (Embree)<br/>• Direct solar flux<br/>• Primary reflection<br/>• Primary IR emission"]

        thermal["🌡️ Thermal Model<br/>• Equilibration (FFT)<br/>• Crank-Nicolson solver<br/>• T-dependent properties"]

        radiation["🔄 Radiation Exchange<br/>• View factors<br/>• H-matrix compression<br/>• Radiosity solver"]

        coupling["🔗 Thermal-Radiation<br/>Coupling Loop"]

        ice["❄️ Ice Stability<br/>• Vapor diffusion<br/>• Newton-Raphson<br/>• Depth calculation"]
    end

    subgraph OUTPUTS["📤 OUTPUTS"]
        binary[("Binary Files<br/>temperature.bin<br/>illumination.bin")]
        vtk[("VTK/PVD<br/>ParaView<br/>Animation")]
        csv[("CSV Series<br/>Location data<br/>Time series")]
    end

    mesh --> meshgen
    spice --> illum
    config --> meshgen

    meshgen --> illum
    illum --> thermal
    thermal --> radiation
    radiation --> coupling
    coupling -->|"converged"| ice
    coupling -->|"iterate"| thermal
    thermal -->|"no radiation"| ice

    ice --> binary
    ice --> vtk
    ice --> csv

    style INPUTS fill:#e1f5fe
    style PROCESSING fill:#fff3e0
    style OUTPUTS fill:#e8f5e9
```

OPTION 4: PYTHON MATPLOTLIB (programmatic generation)
================================================================================

```python
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch

fig, ax = plt.subplots(1, 1, figsize=(12, 16))
ax.set_xlim(0, 10)
ax.set_ylim(0, 16)
ax.set_aspect('equal')
ax.axis('off')

# Define box style
box_style = dict(boxstyle="round,pad=0.3", facecolor='lightblue', edgecolor='navy', linewidth=2)

# Helper function to draw boxes
def draw_box(ax, x, y, width, height, text, color='lightblue'):
    box = FancyBboxPatch((x, y), width, height,
                         boxstyle="round,pad=0.1",
                         facecolor=color, edgecolor='navy', linewidth=2)
    ax.add_patch(box)
    ax.text(x + width/2, y + height/2, text, ha='center', va='center',
            fontsize=9, fontweight='bold', wrap=True)

# Draw boxes (from top to bottom)
draw_box(ax, 3, 14.5, 4, 1, 'INPUTS\nMesh | SPICE | Config', '#E3F2FD')
draw_box(ax, 3, 12.5, 4, 1.2, 'Mesh Generation\n• Icosphere\n• Normals', '#FFF3E0')
draw_box(ax, 3, 10.3, 4, 1.4, 'Illumination Model\n• Ray tracing\n• Solar flux', '#FFF3E0')
draw_box(ax, 3, 8.1, 4, 1.4, 'Thermal Model\n• Equilibration\n• Crank-Nicolson', '#FFF3E0')
draw_box(ax, 3, 5.9, 4, 1.4, 'Radiation Exchange\n• View factors\n• Radiosity', '#FFF3E0')
draw_box(ax, 3, 3.7, 4, 1.4, 'Ice Stability\n• Vapor diffusion\n• Newton-Raphson', '#FFF3E0')
draw_box(ax, 3, 1.5, 4, 1, 'OUTPUTS\nBinary | VTK | CSV', '#E8F5E9')

# Draw arrows
for y_start, y_end in [(14.5, 13.7), (12.5, 11.7), (10.3, 9.5), (8.1, 7.3), (5.9, 5.1), (3.7, 2.5)]:
    ax.annotate('', xy=(5, y_end), xytext=(5, y_start),
                arrowprops=dict(arrowstyle='->', color='navy', lw=2))

plt.title('PTM3D Simulation Workflow', fontsize=14, fontweight='bold', pad=20)
plt.tight_layout()
plt.savefig('ptm3d_workflow.png', dpi=150, bbox_inches='tight', facecolor='white')
plt.show()
```
