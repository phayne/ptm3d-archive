# Polar Wander Figure Captions

Figures generated by `scripts/polar_wander_cycle.py`, which implements
cyclical polar wander driven by trailing-hemisphere magnetospheric
darkening on Europa's ice shell.

All simulations use the Maxwell $H$=0 rheology case unless otherwise
noted.

---

|-----------|--------|-------|

## Run 1: Exponential TPW (`docs/figures/polar_wander/`)

**TPW model**: `exponential` — free-parameter relaxation timescale.
The spin pole relaxes toward the maximum-MoI eigenvector with:

$$\Delta\alpha = \delta\,(1 - e^{-\Delta t / \tau_{\rm TPW}})$$

| Parameter | Value |
|-----------|-------|
| $\tau_{\rm TPW}$ | $10^5$ yr |
| $\Delta t$ | $10^4$ yr |

**Reproduction command:**
```bash
cd /path/to/ptm
python scripts/polar_wander_cycle.py \
    --tpw-model exponential \
    --tau-tpw 1e5 \
    --t-max 1e8 \
    --save-dir docs/figures/polar_wander \
    --format pdf --dpi 300
```

### `fig1_quasi_static.pdf`

**Caption.** Quasi-static stability analysis for Europa's ice shell
under progressive trailing-hemisphere darkening (Maxwell $H$=0
rheology, fossil bulge $\alpha=1.5$).
**(a)** Non-dimensional moment-of-inertia instability parameter
$\Delta(B-C)/A$ (units of $10^{-8}$) versus darkening fraction $f$

Solid curve shows the total (shell + fossil) value; with the fossil

line marks the critical darkening $f_{\rm crit}$ where
$\Delta(B-C)/A$ crosses zero.  Upper axis shows the corresponding
area-mean albedo $\langle A \rangle$.
**(b)** Misalignment angle between the current spin pole and the
maximum-MoI eigenvector $\hat{v}_{\rm max}$ as a function of $f$.  The
dashed line marks the 5° milestone threshold used for event logging.

### `fig2_time_series.pdf`

**Caption.** Time evolution of a 100 Myr polar wander simulation with

**(a)** Darkening fraction $f(t)$ — rises exponentially on

**(b)** Area-mean Bond albedo $\langle A \rangle$.

**Caption.** Mollweide projections of equilibrium ice shell thickness

**(b)** $f=0.25$: incipient trailing-hemisphere thinning.
**(c)** $f=0.75$: strong trailing thinning.
**(d)** $f=1.0$ (fully darkened): trailing hemisphere (right side of

## Run 2: OSPW TPW (`docs/figures/polar_wander_ospw/`)

**TPW model**: `ospw` — Ojakangas & Stevenson (1989) overdamped
pendulum model.  The spin pole angular velocity is determined by the
balance between tidal driving torque and viscous dissipation in the
ice shell:

$$\omega = \frac{2\varepsilon^2 n^2 I_0}{C_f}\,\sin(2\psi)$$

where $\varepsilon$ is the triaxiality parameter (with OSPW
bottom-loading correction), $n$ is the mean motion, $I_0$ is the
shell moment of inertia, $C_f$ is the viscous friction coefficient,
and $\psi$ is the misalignment angle.  The iceberg effect amplifies
the driving by a factor of ~8.4× through bottom-loading of the
ice-ocean density contrast.

| Parameter | Symbol | Value |
|-----------|--------|-------|
| Shell thickness | $b_c$ | 20 km |
| Lithosphere thickness | $d$ | 2 km |
| Melting viscosity | $\eta_0$ | $3 \times 10^{14}$ Pa s |
| Activation parameter | $l$ | 15 |
| Fracture base temperature | $T_f$ | 130 K |
| Surface temperature | $T_s$ | 100 K |
| Iceberg effect | — | ON (auto-computed) |
| $\Delta t$ | — | 10 kyr (auto-selected from $\tau_f/100$) |

**Derived quantities** (computed at runtime):
- $C_f \approx 1.9 \times 10^{27}$ kg m²/s (viscous friction)
- $\tau_f \approx 1.0$ Myr (OSPW relaxation timescale)
- OSPW epsilon correction $\approx 0.048$

**Reproduction command:**
```bash
python scripts/polar_wander_cycle.py \
    --tpw-model ospw \
    --ospw-Tf 130 --ospw-eta0 3e14 --ospw-l 15 \
    --ospw-bc 20 --ospw-d-lith 2 \
    --t-max 1e8 \
    --save-dir docs/figures/polar_wander_ospw \
    --format pdf --dpi 300
```

### `fig1_quasi_static.pdf`

**Caption.** Same as Run 1 `fig1_quasi_static.pdf`.  The quasi-static
sweep is independent of the TPW dynamics model (it computes the
equilibrium inertia tensor at each darkening fraction $f$).

### `fig2_time_series.pdf`

**Caption.** Time evolution with OSPW overdamped TPW dynamics over
100 Myr.  Panels (a)–(f) as in Run 1.  Additional panel:
**(g)** TPW angular velocity $\omega_{\rm TPW}$ [deg/Myr] on a
symlog scale (linear below 10 deg/Myr, logarithmic above).  This
diagnostic shows the instantaneous rate at which the spin pole drifts
toward the maximum-MoI eigenvector.

Key difference from exponential mode: the OSPW timescale ($\tau_f
\sim 1$ Myr) is physically derived from shell viscosity rather than
being a free parameter.  The pole still enters continuous rotation
after the fossil decays, but the rotation rate is governed by the
overdamped torque balance rather than by exponential relaxation.

### `fig4_mollweide.pdf`

**Caption.** Same as Run 1 `fig4_mollweide.pdf`.  Shell thickness
snapshots are independent of the TPW model (they show the equilibrium
thickness at each darkening fraction).

### `fig6_spin_pole.pdf`

**Caption.** Spin pole trajectory with OSPW overdamped dynamics.
Layout identical to Run 1 `fig6_spin_pole.pdf`.  The trajectory
should be qualitatively similar (continuous rotation along the
trailing–leading meridian) but may differ in rate and onset time
due to the physically derived damping timescale.

## Run 3: Coupled TPW — Weak Interior Coupling (`docs/figures/polar_wander_coupled/`)

**TPW model**: `coupled` — OSPW viscous dissipation plus Burnett &
Hayne (2023) gravity-gradient coupling between the ice shell and the
rocky interior.

Two torques act on the shell in different directions:
1. **Driving** (toward $\hat{v}_{\rm max}$): OSPW overdamped torque,
   same as Run 2
2. **Coupling** (toward interior pole): gravity-gradient restoring
   torque $\propto K_G \sin(2\delta)$, where $\delta$ is the angular
   separation between the shell spin axis and the interior spin axis

The interior responds to the same coupling torque (equal and opposite),
evolving on its own timescale modulated by $\gamma = C_i/C_s$.

| Parameter | Symbol | Value | Notes |
|-----------|--------|-------|-------|
| OSPW parameters | — | Same as Run 2 | — |
| Interior/shell MoI ratio | $\gamma$ | 28 | $C_i / C_s$ |
| Interior triaxiality | $(B_i - A_i)/C_i$ | $10^{-5}$ | Rigid interior |
| Coupling strength | $K_G / K_G^*$ | 0.5 | Weak coupling |

**Derived**: $K_G \approx 2.6 \times 10^{19}$ N m (gravity-gradient
coupling torque scale).  With rigid interior ($\varepsilon_i = 10^{-5}$),
the coupling is negligible — the shell rotates essentially freely.

**Reproduction command:**
```bash
python scripts/polar_wander_cycle.py \
    --tpw-model coupled \
    --ospw-Tf 130 --ospw-eta0 3e14 --ospw-l 15 \
    --ospw-bc 20 --ospw-d-lith 2 \
    --interior-gamma 28 \
    --interior-triaxiality 1e-5 \
    --interior-KG-factor 0.5 \
    --t-max 1e8 \
    --save-dir docs/figures/polar_wander_coupled \
    --format pdf --dpi 300
```

### `fig1_quasi_static.pdf`

**Caption.** Same as Runs 1–2.

### `fig2_time_series.pdf`

**Caption.** Time evolution with coupled (OSPW + B&H interior)
dynamics over 100 Myr, using weak interior coupling
($\varepsilon_i = 10^{-5}$, rigid interior).  Panels (a)–(f) as in
Run 1.  Additional panels:
**(g)** TPW angular velocity $\omega_{\rm TPW}$ [deg/Myr] on symlog
scale.
**(h)** Shell–interior angular separation [degrees] — the angle
between the ice shell spin axis and the rocky interior spin axis.

With a rigid interior ($\varepsilon_i = 10^{-5}$), the coupling torque
$K_G$ is negligible ($\sim 10^{19}$ N m), so the shell evolves
essentially identically to the OSPW-only case (Run 2).  The interior
pole remains nearly fixed while the shell rotates freely.

### `fig4_mollweide.pdf`

**Caption.** Same as Runs 1–2.

### `fig6_spin_pole.pdf`

**Caption.** Spin pole trajectory with coupled dynamics (weak coupling,
rigid interior).  Layout identical to Run 1.  Behavior closely
matches the OSPW-only case since interior coupling is negligible.

## Run 4: Coupled TPW — Strong Interior Coupling (`docs/figures/polar_wander_coupled_strong/`)

**TPW model**: `coupled` — same physics as Run 3, but with a
**hydrostatic interior** ($\varepsilon_i = 5 \times 10^{-4}$) that
provides much stronger gravity-gradient coupling.

| Parameter | Symbol | Value | Notes |
|-----------|--------|-------|-------|
| OSPW parameters | — | Same as Run 2 | — |
| Interior/shell MoI ratio | $\gamma$ | 28 | $C_i / C_s$ |
| Interior triaxiality | $(B_i - A_i)/C_i$ | $5 \times 10^{-4}$ | Hydrostatic interior |
| Coupling strength | $K_G / K_G^*$ | 0.5 | Moderate coupling |

**Derived**: $K_G \approx 1.3 \times 10^{21}$ N m — 50× stronger
than the rigid-interior case.  The coupling torque can now resist the
OSPW driving torque, significantly altering the shell's reorientation
behavior.

**Reproduction command:**
```bash
python scripts/polar_wander_cycle.py \
    --tpw-model coupled \
    --ospw-Tf 130 --ospw-eta0 3e14 --ospw-l 15 \
    --ospw-bc 20 --ospw-d-lith 2 \
    --interior-gamma 28 \
    --interior-triaxiality 5e-4 \
    --interior-KG-factor 0.5 \
    --t-max 1e8 \
    --save-dir docs/figures/polar_wander_coupled_strong \
    --format pdf --dpi 300
```

### `fig1_quasi_static.pdf`

**Caption.** Same as Runs 1–3.

### `fig2_time_series.pdf`

**Caption.** Time evolution with coupled dynamics and strong interior
coupling (hydrostatic interior, $\varepsilon_i = 5 \times 10^{-4}$)
over 100 Myr.  Panels (a)–(f) as in Run 1.  Additional panels:
**(g)** TPW angular velocity $\omega_{\rm TPW}$ [deg/Myr] on symlog
scale.
**(h)** Shell–interior angular separation [degrees].

Key differences from Run 3 (weak coupling):
- **Delayed onset**: The interior coupling resists shell reorientation,
  delaying the onset of TPW from $\sim 5$ Myr to $\sim 16$ Myr.
- **Episodic jumps**: Rather than smooth continuous rotation, the shell
  undergoes a discrete $\sim 90°$ reorientation before transitioning
  to continuous rotation (visible in the $\theta_s$ panel).
- **Shell–interior separation**: Panel (h) shows large separation
  angles ($\sim 180°$) as the coupling torque is overcome by the
  driving torque once the fossil bulge has decayed sufficiently.

### `fig4_mollweide.pdf`

**Caption.** Same as Runs 1–3.

### `fig6_spin_pole.pdf`

**Caption.** Spin pole trajectory with coupled dynamics (strong
coupling, hydrostatic interior).  Layout identical to Run 1.  The
trajectory shows delayed onset and a qualitatively different initial
breakout pattern compared to the weak-coupling cases (Runs 1–3),
with the pole initially jumping rapidly before settling into
continuous rotation.

## Notes on Figure Reproducibility

1. **Random seed**: The simulations are deterministic (no stochastic
   elements), so identical parameters produce identical results.

2. **Python dependencies**: NumPy, Matplotlib, SciPy.  The OSPW
   module `scripts/ospw_polar_wander.py` and constants from
   `src/python/ojakangas_stevenson/constants.py` must be importable.

3. **PYTHONPATH**: Run from the project root, or set:
   ```bash
   export PYTHONPATH=/path/to/ptm/src/python:$PYTHONPATH
   ```

4. **Runtime**: Each 100 Myr simulation takes approximately 1–5
   minutes on a modern CPU, depending on the TPW model and timestep.

5. **Figures not regenerated**: `fig3_cycle_period.pdf` and
   `fig5_all_rheologies.pdf` are produced only with `--survey` or
   `--all-rheologies` flags and are not part of these four standard
   run sets.
