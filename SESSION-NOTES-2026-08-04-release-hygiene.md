## Item 2 — the PTM-37 test fixtures

Three synthetic PLYs, regenerated by this script (icosphere subdivision 2, 320 faces):

```python
import math
def icosphere(subdiv):
    t=(1+5**0.5)/2
    v=[[-1,t,0],[1,t,0],[-1,-t,0],[1,-t,0],[0,-1,t],[0,1,t],[0,-1,-t],[0,1,-t],
       [t,0,-1],[t,0,1],[-t,0,-1],[-t,0,1]]
    f=[[0,11,5],[0,5,1],[0,1,7],[0,7,10],[0,10,11],[1,5,9],[5,11,4],[11,10,2],[10,7,6],[7,1,8],
       [3,9,4],[3,4,2],[3,2,6],[3,6,8],[3,8,9],[4,9,5],[2,4,11],[6,2,10],[8,6,7],[9,8,1]]
    for _ in range(subdiv):
        cache={}; nf=[]
        def mid(a,b):
            k=(min(a,b),max(a,b))
            if k in cache: return cache[k]
            v.append([(v[a][i]+v[b][i])/2 for i in range(3)]); cache[k]=len(v)-1; return cache[k]
        for a,b,c in f:
            ab,bc,ca=mid(a,b),mid(b,c),mid(c,a)
            nf += [[a,ab,ca],[b,bc,ab],[c,ca,bc],[ab,bc,ca]]
        f=nf
    for i,p in enumerate(v):
        n=math.sqrt(sum(x*x for x in p)); v[i]=[x/n for x in p]
    return v,f

def write_ply(path, verts, faces):
    with open(path,'w') as fh:
        fh.write("ply\nformat ascii 1.0\ncomment PTM-37 guard test fixture\n")
        fh.write("element vertex %d\nproperty float x\nproperty float y\nproperty float z\n"%len(verts))
        fh.write("element face %d\nproperty list uchar int vertex_indices\nend_header\n"%len(faces))
        for p in verts: fh.write("%.6f %.6f %.6f\n"%tuple(p))
        for f in faces: fh.write("3 %d %d %d\n"%tuple(f))

uv, uf = icosphere(2)
# ambiguous: uniform radius 8687 -- inside the band, matches neither 1737.4 km nor 1737.4e3 m
write_ply('C_ambiguous.ply', [[8687.0*x for x in p] for p in uv], uf)
# gas giant: uniform radius 71492 -- heuristic says METERS, R_body says KILOMETERS
write_ply('E_gasgiant.ply', [[71492.0*x for x in p] for p in uv], uf)
# straddle: TWO disjoint shells at r=5000 plus ONE at r=50000, so |fc| spans 10,000
verts=[]; faces=[]
for r,copies in ((5000.0,2),(50000.0,1)):
    for _ in range(copies):
        off=len(verts)
        verts += [[r*x for x in p] for p in uv]
        faces += [[a+off,b+off,c+off] for a,b,c in uf]
write_ply('D_straddle.ply', verts, faces)
```

## Item 6 — PTM-51: Fermi's mechanism, measured

`PTM_DUMP_EQ_SEED=<path.csv>` (new, `[internal]`, default off, byte-identical when unset — verified
by running DNH-1 with it on and off).

Moon global topo res7, 327,680 faces, 96 steps, eq 1.0, CPU, 59 s:

| quantity | PTM-51 as written | Fermi | **measured** |
|---|---|---|---|
| `T_deep − T_surf_est`, zero-flux faces | 50 K (cap active) | ~2.5 K | **2.489393 K** |
| faces at the 50 K cap | most | none | **0 of 327,680** |
| equilibration forcing, zero-flux faces | 0 | ~0.5 W/m² | **9.36 – 56.20 W/m², median 20.74** |

The seed cannot be the reservoir: its warmest cell is `24.0426 + 2.4894 = 26.53 K`, and those faces
finish at 52.60 – 63.41 K. Across the 16 zero-flux faces the seed terms are identical to 7 digits
while the forcing varies 6× with latitude, and the final temperature is a **perfectly monotone**
function of the forcing (Spearman ρ = 1.0000, Pearson r = 0.9815). PTM-51's headline 63.6 K is the
hottest, lowest-latitude member of that population (63.41 K at lat −81.52°).

Mechanism: the equilibration forcing is
`planet.S*(1-albedo)*max(0, cos(lat)*cos(hour_angle))` (`ptm_thermal_sim.cpp:3305-3310`) — analytic
clear sky, a function of **latitude alone**. It knows nothing about topography or shadowing, so a
face that receives exactly 0 W/m² in the real geometry is equilibrated as if it were clear sky.

Fermi's 0.5 W/m² estimate was low by a latitude assumption (0.5 W/m² corresponds to |lat| ≈ 89.9°;
the zero-flux population here is 81.5–88.6°), not by a mechanism error.

**Consequence for any future fix:** reseeding the column with a conduction-consistent linear profile
would not help. The heat arrives during equilibration, not from the seed.
